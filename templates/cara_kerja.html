INFORMASI SISTEM

Cara Kerja Sistem

Alur proses prediksi produksi telur bebek menggunakan Random Forest Regression.

01
Input Data
Sistem menggunakan data produksi telur dan faktor yang memengaruhinya sebagai dasar pemodelan.
  • Populasi Bebek Ratu
  • Populasi Bebek Air
  • Populasi Total
  • Kepadatan Kandang
  • Pakan
  • Kondisi Cuaca
  • Suhu
  • Kelembapan
  • Curah Hujan
  • Usia Bebek
02
Pembagian Data
Dataset dibagi menjadi data training sebesar 80% dan data testing sebesar 20%.
03
Pelatihan Random Forest
Model Random Forest Regression dilatih menggunakan data training untuk mempelajari hubungan antara variabel input dan produksi telur.
04
Optimasi Parameter
Parameter model ditentukan menggunakan GridSearchCV dengan cross-validation untuk mendapatkan kombinasi parameter yang sesuai.
05
Pengujian Model
Model yang telah dilatih diuji menggunakan data testing untuk mengetahui kemampuan model dalam melakukan prediksi.
06
Evaluasi
Performa model dievaluasi menggunakan MAE, RMSE, MAPE dan R².
07
Prediksi Produksi
Setelah model tersedia, pengguna dapat memasukkan kondisi peternakan untuk memperoleh estimasi jumlah produksi telur.
